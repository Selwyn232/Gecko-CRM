# Huisstijl

| Bestand | Gebruik |
|---|---|
| `gecko-logo.png` | Opgeschoond logo (alleen gecko en boog, transparant, 1024 px). Bron voor iconen in de webapp (`apps/web/public/gecko-logo-*.png`, `apple-touch-icon.png`) |
| `gecko-logo-origineel.png` | Het aangeleverde logo, met de rood-gele vlekjes rondom |

## Kleuren

| Token | Licht | Donker | Gebruik |
|---|---|---|---|
| `--accent` | `#FC8801` | `#FC8801` | Vlakken: knoppen, actief, icoon (oranje van het logo) |
| `--on-accent` | `#1C1712` | `#1C1712` | Tekst op oranje (contrast 7:1; wit op dit oranje is te zwak) |
| `--accent-text` | `#A94800` | `#FFA64D` | Oranje tekst en links (leesbaar op de achtergrond) |
| `--accent-soft` | `#FFF1E0` | `#3A2410` | Lichte achtergrond, bv. actief menu-item |
| `--success` | `#1F7A4D` | `#3FB57A` | Positief: actief, geaccepteerd, betaald (bewust groen) |

E-mails gebruiken hetzelfde oranje voor de kopregel en de knoppen (donkere tekst).
